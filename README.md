Network Guardian – Network Monitoring and Anomaly Detection
An educational Windows-based network monitoring and intrusion-detection prototype built with Python. It combines rule-based security monitoring with machine-learning-based anomaly detection.
Project Features
* Live Packet Capture: Captures network packets from a selected network interface using Scapy and Npcap.
* Traffic Monitoring: Displays captured packets and TCP, UDP and ICMP statistics.
* Traffic Analysis: Extracts packet sizes, destination ports, DNS query counts and source IP addresses.
* Port Scan Detection: Uses rule-based detection to identify possible port-scanning activity.
* DNS Monitoring: Identifies repeated DNS queries and suspicious-looking domain patterns.
* Machine Learning: Uses Isolation Forest to identify unusual network traffic windows.
* Database: Stores traffic records and security alerts using SQLite.
* Desktop Dashboard: Provides a graphical interface built with Python Tkinter.

Installation and Setup
1. Install Python if it is not already installed.
2. Install Npcap from the official Npcap website.
3. Download or clone this repository.
4. Extract the project into a normal folder.
5. Double-click launch_network_guardian.bat.
6. The launcher creates a virtual environment and installs the required Python dependencies.
7. Once the application opens, click Find interfaces.
8. Select your active network interface and click Start monitoring.
If packet capture fails, try running the launcher as Administrator.
Using Network Guardian
Network Monitoring
* Select the network interface.
* Start monitoring.
* Observe captured packets and traffic statistics.
* Review the live traffic windows and security alerts.
* Stop monitoring when finished.
AI Anomaly Detection
Network Guardian uses the Isolation Forest algorithm for unsupervised anomaly detection.
To train the model:
1. Start monitoring and collect traffic feature records.
2. Collect a representative baseline over multiple sessions.
3. Ensure the minimum training-data requirement is met.
4. Click Train AI model.
5. The trained model is saved under models/ and can be loaded during future application launches.
The model identifies traffic patterns that differ from its learned baseline. An anomaly alert does not independently confirm malicious activity.

Current Limitations
* This is an educational prototype, not an enterprise-grade intrusion detection system.
* Rule-based detection uses simple heuristics and may produce false positives or miss suspicious activity.
* Isolation Forest anomaly detection requires a representative training baseline.
* Detection accuracy and false-positive rates require further independent testing.
* Packet visibility depends on the selected interface, Windows, Npcap, network drivers and network topology.
* The application generally observes traffic visible to the computer's selected network interface, not all traffic generated by every device on a Wi-Fi network.
* DNS-over-HTTPS and DNS-over-TLS contents are not inspected.
Future Improvements

Security and Ethical Use
Use Network Guardian only on networks and devices you own or have explicit permission to monitor.
Anomaly alerts are investigation indicators, not proof of compromise.
